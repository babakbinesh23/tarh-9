# طرح ۹ — Living Energy Flow | برقتو

**A Persian conceptual landing page visualizing connected solar-energy production.**

> **نوع پروژه:** طرح مستقل UI/UX و فرانت‌اند استاتیک، مناسب بررسی و مقایسه ایده‌های طراحی؛ نه سامانه عملیاتی فروش یا پایش برق.

## هدف طراحی

روایت بصری جریان انرژی از تولید تا اتصال به شبکه و فروش. این طرح برای بررسی زبان بصری و روایت دیجیتال خدمات تجمیع برق خورشیدی برقتو ایجاد شده است.

## عناصر شاخص

- پیام «یک جریان زنده از نور تا درآمد»
- شبکه نیروگاه‌ها و مسیر پیوستن به برقتو
- ویجت‌های تولید امروز و سلامت نیروگاه
- انیمیشن و بخش‌های تعاملی تجربه کاربری

## فناوری و فایل‌ها

- **HTML / CSS / JavaScript** — کد این نسخه در فایل `index.html` تجمیع شده است.
- **کتابخانه‌ها و منابع:** GSAP، ScrollTrigger، Lenis و فونت Vazirmatn از CDN.
- رابط فارسی راست‌به‌چپ، مناسب مشاهده در مرورگرهای جدید.


## پیش‌نمایش آنلاین / Live demo

**[اجرای آنلاین tarh-9](https://babakbinesh23.github.io/tarh-9/)** — صفحه GitHub Pages در بررسی ۲۱ نوامبر ۲۰۲۶ قابل دسترسی بود. نمایش صحیح همه تعاملات و اتصال فرم‌ها جداگانه باید تست شود.

## اجرای محلی

از ریشه مخزن، فایل `index.html` را در مرورگر باز کنید. برای پیش‌نمایش با سرور استاتیک:

```bash
python -m http.server 8000
```

سپس `http://localhost:8000/` را باز کنید. نیاز به npm، دیتابیس یا فرآیند Build نیست. انیمیشن‌ها و فونت‌های CDN برای نمایش کامل نیاز به اینترنت دارند.

## محدودیت‌ها و ملاحظات

- ویجت‌های تولید و سلامت نیروگاه در این نمونه نباید به‌عنوان پایش داده‌های واقعی معرفی شوند.
- محاسبه‌های مالی/فنی و آمار باید قبل از استفاده واقعی با داده معتبر راستی‌آزمایی شوند.
- برای اتصال فرم‌ها به CRM، احراز هویت، ثبت داده و مدیریت اطلاعات شخصی به بک‌اند ایمن نیاز است.
